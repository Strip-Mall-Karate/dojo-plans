# Dojo package: pngquant

Lossy PNG compressor.

## Maintainers

Strip Mall Karate Company.

## Type of package

Library package. Include this plan as a runtime or build dependency for plans that require `pngquant`.

## Usage

```
pkg_deps=(
  karate/pngquant
)
```

or

```
pkg_build_deps=(
  karate/pngquant
)
```
