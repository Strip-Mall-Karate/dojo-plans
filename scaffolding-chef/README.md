# Chef Scaffolding for Dojo

This will take a Chef policy file, and build it for use as a dojo service.

```
scaffold_policy_name="base"
pkg_name=chef-base
pkg_origin=adam
pkg_version="0.1.0"
pkg_maintainer="Strip Mall Karate Company"
pkg_license=("Apache-2.0")
pkg_description="The Chef $scaffold_policy_name Policy"
pkg_upstream_url="http://chef.io"
pkg_scaffolding="karate/scaffolding-chef"
```
