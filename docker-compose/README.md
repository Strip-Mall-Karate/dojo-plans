# Docker Compose

[Compose](https://docs.docker.com/compose/) is a tool for defining and running multi-container Docker applications.

## Maintainers

Strip Mall Karate Company

## Type of Package

binary wrapper package

## Usage

```bash
doj pkg install karate/docker-compose
doj pkg binlink karate/docker-compose docker-compose   # do not try to binlink all the python deps

docker-compose --version
```
