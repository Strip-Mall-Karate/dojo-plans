# boost159

Boost provides free peer-reviewed portable C++ source libraries.

> Note: this package is required by `karate/mysql` and `karate/mysql-client` packages, you should use `karate/boost` in your packages instead.

## Maintainers

* Strip Mall Karate Company

## Type of Package

Binary package

## Usage

This is a library usually used at build time, thus you should use it like so in your plans:

```
pkg_build_deps=(
    karate/boost159
)
```
